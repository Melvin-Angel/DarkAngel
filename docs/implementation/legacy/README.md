# Archived implementation documentation

This directory contains the implementation reports, milestone plans,
chronological handoffs, prompts and research documents that existed before the
17 October 2026 clean-slate reset.

- `current-archive-2026-10-17/` contains the former current reports and
  checkpoint documents.
- `future-archive-2026-10-17/` contains the former future plans and backlogs.
- `roadmap-archive-2026-10-17/` contains the former authoritative roadmap.
- `tool-archive-2026-10-17/` contains bootstrap-generated M0 reports; the
  bootstrap helper writes there and cannot overwrite active status.
- `milestones/`, `increments/`, `plans/` and `prompts/` are older historical
  material that was already archived.

These files preserve evidence and design history. Their dated status language
does not describe the current implementation state. Start with
`../current/CURRENT_PHASE.md`, `../STATUS.md` and
`../future/DEFERRED_WORK.md` instead.
