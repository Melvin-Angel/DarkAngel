# Public ability state and prepared observer presentation

9 October 2026, following ee841f5. M4/M5 remain **In progress**.

The existing WorldSession protocol-3 path now publishes a coherent public motor/action frame to current and late clients. Each frame carries current action identity, pinned definition generation, clock/rate and explicitly public attribute values. It has no private ability grants, inputs, operation receipts, costs or cooldowns. Health/MaxHealth retain their existing public ObjectData contract. Other attributes follow the visibility already authored in `.daattributes`; server-only values are also excluded from private owner corrections. The native schema now retains cooked visibility instead of dropping it when configuring AbilityState.

Public frames are sent only after motor publication and resolution of authoritative hit work. Reliable object revision, network/session identity and avatar epoch fence their publication. A late client receives the current ongoing phase and resource outcomes without replaying previous timeline markers, damage or start cues. Death/completion/cancellation are current state, and a new reliable object baseline clears old public references and partial fragments. No new transport or combat world is introduced.

The versioned public codec has a 4096-byte bound, up to five 896-byte fragments and packets below the existing 1000-byte budget. Current arena-wide interest remains bounded to four configured motor/ability actors. Reordered identical fragments are accepted; conflicting duplicates, direction/profile/schema violations, incoherent motor/action ticks, nonfinite or duplicate attributes and malformed action states fail. Incomplete groups expire into a per-actor resync state; periodic complete keyframes recover them. Frozen fragment groups are never published partially.

ObserverAbility prepares an actor's public schema and immutable native action catalogue before accepting frames. It keeps at most eight coherent frames and samples movement and action phase on the same caller-selected delayed render clock. It interpolates a continuing action, preserves activation transitions, honors rate-zero hitstop, extrapolates at most two ticks, then holds. Sampling has no gameplay/root/event sink. Unknown/private attributes or incompatible action generations leave the prior buffer intact. Reliable world revision, avatar epoch and topology changes reset history; actor/session replacement requires a fresh/reset buffer. Automatic jitter-buffer tuning remains open.

Royal now prepares these native buffers for its player and target through the same serialized composition. The native fixture checks delayed attack phase and public Health while retaining private Stamina/Essence. The stationary target's graphical rest pose and broader external-provider/remote rendering workflows remain separate gates. Owner prediction requires visible cost/resource-bound attributes; a server-only dependency fails native prediction preparation explicitly.
