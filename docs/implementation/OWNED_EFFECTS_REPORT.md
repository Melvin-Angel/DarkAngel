# Native owned effects and tags

9 October 2026, following precise Royal collision checkpoint 5e1d098. M4/M5 remain **In progress**.

The existing server AbilityState now owns its native effect instances and tag contributions alongside attributes, grants and action execution. WorldSession exposes checked owner-generation/domain application, removal and cleanse methods; clients cannot mutate them. This adds no world, networking runtime, asset format or dependency.

An immutable native tag dictionary validates stable IDs, parents, cycles, depth, visibility and bounded All/Any/None requirements. Queries include descendants. Every contributor retains an exact token, so overlapping Burn/slow sources remain independent during cleanup. Ongoing suppression evaluates the same current tag view for every effect while excluding its own token, then publishes the new contributions together. Suppressed periods advance without execution or catch-up replay. This is a bounded simultaneous policy pass, not recursive dependency evaluation.

Effect definitions are copied and pinned at application. Lifetimes are Instant, Finite `[start,end)` and UntilRemoved; immediate execution is explicit, and periodic execution first occurs at `start+period`. Expiry and periodic work across all owners precede activation and use the simulation tick even during action hitstop. Independent stacking and refresh per source are explicit. Burn refresh preserves identity and periodic phase, updates captured credit/magnitude and extends finite expiry. Different source actors retain separate contributions. Generation changes require removing/replacing the existing instance.

Native game-owned evaluators receive read-only captured source attributes/power/identity and the current target attributes/tags, returning bounded resource deltas. Melee's existing game-owned evaluator also receives native source/target tag views. Damage/defense formulas and invulnerability policy remain game-owned. Captured session/network/activation credit contains no live avatar pointer and survives source destruction. Source-bound equipment explicitly opts into destruction cleanup; independent Burn continues. Death cleans flagged effects/tags/modifiers, releases active action ownership and suppresses later periodic damage work in stable instance order. Stagger can explicitly force active action cleanup. Native cleanse filters each effect's own declared tags through the hierarchical dictionary.

Each mutation prepares copied state, attributes, action cleanup and execution receipts before publication. A shared modifier replacement recomputes once, avoiding permanent resource loss from temporary removal of a maximum-stat modifier. Effect handles include the checked target owner at the WorldSession boundary. Limits include 64 active effects per actor, 16 tags/modifiers/resource deltas per definition/execution, 128 dictionary entries/contribution tokens and 128 undrained execution outcomes. Invalid policy, evaluator output, stale owner, cross-owner handle, capacity or publication failure preserves the prior authoritative state and fixed tick.
