The final independent receipt is [m3-independent.json](evidence/m3-independent.json), with [native CTest](evidence/m3-ctest.log), [GNS host](evidence/m3-gns-host-process.log), [GNS client](evidence/m3-gns-client-process.log) and [official MCP](evidence/m3-mcp.log) logs. It explicitly records online acceptance as unverified. [Online reproduction](M3_ONLINE_ACCEPTANCE.md) lists the private inputs and commands; no secrets or identity tokens are committed.

`WorldSession` shares one explicit little-endian codec and Handshake/ContentReady/Bootstrap/CatchUp/Ready state machine across providers. Transform/health snapshots use at most 1000-byte packets, bounded object/peer/chunk/work limits and a validated candidate world published atomically. ACK follows complete retained decoding. Changes during bootstrap require a current baseline before Ready. Bootstrap has its own reliable channel; control can cross it, so stale Ready messages are discarded. Backpressure preserves captured revisions; malformed messages and deadlines disconnect. Native server entity handles survive movement, and NetworkIds are not reused within a session.

Tests include 23 objects over multiple chunks and a two-packet queue, concurrent bootstrap changes, current late-join move/despawn state, four-peer convergence and fifth-peer rejection, client mutation denial, nonfinite transforms, forged traffic and delayed control crossing newer bootstrap traffic. This initial full-snapshot profile rejects scripts, target references and optional authoring payloads rather than silently losing them. Delta encoding, interest management, gameplay prediction and large-world bindings remain later work. UDP localhost proves process integration, not physical LAN, poor-network or production multiplayer qualification.

GNS remains pinned at 1.6.0. A checksum-verified local vcpkg overlay changes only `Protobuf_USE_STATIC_LIBS` to match the selected static protobuf libraries; the upstream default caused DLL-import linker failures. [Exception record](../../cmake/m3-gns-port-exception.json) records original/overlay hashes and rationale. Dependency versions were not upgraded. M3 uses external `%LOCALAPPDATA%/DarkAngel/vcpkg-buildtrees` so workspace C# tooling cannot lock protobuf extraction output.

EOS remains a separate opt-in target. Ordinary Headless, Loopback and GNS neither link nor initialize EOS. The adapter implements Connect login, explicit account creation, lobby advertisement/search/exact selection, membership and host fences, expiry/refresh and bounded P2P traffic through the common protocol. SDK initialization is process-wide and shutdown final. Compilation and initialization do not verify service behavior: two identities, nonmember rejection, expiry/refresh, reconnect and relay still need live acceptance.

The opt-in native endpoint has a current-user Windows ACL, rejects remote clients, issues a private new descriptor and validates project/host/credential on every request. Owner-thread work, frames, queues, prepared plans, deadlines and operation receipts are bounded. Curated edits use existing `EditorDocument` transactions and remain unsaved until an explicit native save. Revision and history-head checks protect intervening UI edits. Results carry history token, summary and UI/agent origin; identical retries cannot double commit. Document switching replaces authorization. Shipping excludes the agent target.

The separate TypeScript bridge uses pinned Node 24.21.0 and official MCP SDK 1.32.1. Acceptance asserts negotiation of the **2025-11-25 compatibility profile**, with SDK-owned stdio initialization, schemas and structured results. DAE-014's target 2026-07-28 is unsupported by this pin and is not claimed as verified; supporting it requires an explicit dependency review. [Bridge usage](../../tools/agent-bridge/README.md) documents launch, scope and retries. Jobs/resource/capture tool families remain later registered capabilities.

The editor uses centralized gray panels, dark titles/tabs, blue focus/selection and restrained orange Play/unsaved cues. A separate installed Segoe Fluent Icons font loads a small GDI-verified glyph set with readable label fallback; no system font is bundled. DPI changes rescale the base style. Toolbar rows, spacing, IDs/provenance and narrow Inspector values remain readable. Console icons use explicit native severity. Rendering retains the existing Diligent ImGui/ImGuizmo integration.
