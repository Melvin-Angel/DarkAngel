# Current implementation status

Date: 17 October 2026

The current implemented DarkAngel systems are accepted and verified for active
Ashen Roots development. This includes R1–R7 foundations, gameplay, editor,
assets, materials, UI, physics, animation, combat, effects, statuses, NPC
sensing/pathfinding, encounters, interactables, keys, inventory and masks.

The only current qualification exceptions are multi-system/cross-machine
networking and EOS. See [the current phase baseline](current/CURRENT_PHASE.md).

The only active deferred-work list is
[future/DEFERRED_WORK.md](future/DEFERRED_WORK.md). Historical reports and
milestone statuses are in [legacy/](legacy/).
