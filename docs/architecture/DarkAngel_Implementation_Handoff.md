All currently implemented systems are accepted and verified for active Ashen
Roots development. The only current qualification exceptions are multi-system/
cross-machine networking and EOS. R7 is accepted; the old SR0–SR7 rendering
program is retired.

No milestone is automatically active. New work requires a concrete user-
approved objective and focused acceptance criteria.
